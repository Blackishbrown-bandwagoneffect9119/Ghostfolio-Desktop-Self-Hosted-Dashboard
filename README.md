## 🛠️ Troubleshooting - Quick Fixes

If something doesn't work right, try these simple solutions:

**Dashboard doesn't open?** Double-check that you extracted all files fully. Right-click the extracted folder and choose "Extract All" again if needed.

**App says "Port in use"?** This rarely happens. Just restart your computer and try again. The app will find a new port automatically.

**Charts look odd?** Make sure your browser is updated to the latest version. Chrome and Edge work best.

**Forgot your password?** Delete the configuration file in the app folder and restart. You'll create a new profile. (Your investment data is stored separately and will be intact.)
